# グラフ付き動画ビューア

バスケを含む全競技の動画・CSVをグラフとともに確認するビューアです。

```bash
python3 Score/serve_viewer.py
```

http://127.0.0.1:8000/Score/video_graph_viewer.html を開きます。
競技と動画を選択すると、CSVのスコア・勝率・投票率・点数などをグラフ化します。
外部のグラフライブラリやインターネット接続は不要です。

- 点をクリック、またはTabで選んでEnter/Spaceを押すと、その点のCSV参照時刻へ動画を移動し、横の情報も更新します。
- 動画再生中は白い縦線が移動し、現在有効な行の点を白枠で強調します。
- 「表示する項目」で表示系列を選択します。「表示範囲」でgame/Qを選ぶか、開始・終了秒を指定して拡大できます。
- 野球は「表示範囲」で「1回（全体）」「1回表」「1回裏」なども選択できます。範囲は該当イニングの最初〜最後の観測時刻です。CSVに記録のない表・裏は選択肢に含みません。
- スコアは段階線、勝率・投票率は折れ線で表示します。空欄や有効区間の切れ目をまたぐ線は描きません。
- 縦軸は表示範囲のCSV値から自動設定します。整数のみの系列は整数目盛り、小数を含む系列は小数目盛りに対応します。
- 横軸はCSV参照時刻です。「時刻補正」を使った場合、動画の移動先は点の時刻から補正値を引いた時刻です。
- Pokerの同時刻の複数人はプレイヤー別系列で表示し、その時刻に有効な情報をすべて横に表示します。
- 数値のない柔道や競馬などは、イベント・区間のタイムラインを表示します。
- 柔道の一本・技あり・指導は、それぞれwhite（白線）とblue（青線）を同じグラフに表示します。
- 麻雀の局（round_number）と本場（honba）は、「局の推移」「本場の推移」の別々のグラフとして初期表示します。
- `score_before`は区間開始、`score_after`はイベント時刻に点を置きます。動画移動先も同じ適用時刻です。
- Shadowverseは各`game_id`の最初〜最後のスコア・投票率の観測時刻を有効区間とし、ゲーム間は区間外です。別の区間CSVは適用しません。

データ検出は`viewer_catalog.py`、時刻処理は`video_viewer_core.js`、共通スタイルは`video_viewer.css`を使用します。
元のCSVは保持しています。
